# GPT 連携用：SIDRA STUDIO ホームページの引継ぎ

ChatGPT（経営・営業・世界観の相談をしているルーム）に貼り付けて、
**ホームページの現在地と、ここまでの決定の経緯**を共有するための文書です。

## 使い方

1. 下の「貼り付ける本文」から「ここまで」までをすべてコピーして、GPT のルームに貼る
2. GPT は、リポジトリの中身やこの会話は見られません。書いてあることだけが前提です
3. GPT から出た決定事項や文章は、こちらのルームに貼れば、サイトへ反映できます

長いので、貼ったあと GPT に「要約して、決まっていないことを一覧にして」と頼むと、
読み取れているかを確認できます。

10. **自動化**：公開手前まで進めるチェック環境とバックログを構築。ドメイン取得・商標・
