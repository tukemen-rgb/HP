# 別ルーム連携用：パーパス／ビジョン／バリューの依頼文

別のチャット（こちらの会話を参照できないルーム）に貼り付けて、
パーパス・ビジョン・バリューの原案を出してもらうための依頼文です。

## 使い方

1. 下の「貼り付ける本文」をすべてコピーして、別ルームに貼る
2. 返ってきた回答をそのままこちらのルームに貼る
3. 内容を確定させ、サイトの各ページに反映する

出力フォーマットを指定してあるので、返ってきたテキストをそのまま貼れば反映できます。
フォーマットが崩れて返ってきた場合も、こちらで整えます。

---

## 貼り付ける本文

ここから下をコピーしてください。

---

私のゲーム開発会社「SIDRA STUDIO」のパーパス・ビジョン・バリューの原案をつくってください。
つくった原案は、別で制作している企業サイトの文章にそのまま反映します。

あなたがこれまでの会話から知っている私の性格、話し方、意思決定のクセを踏まえて書いてください。
一般論ではなく、私という個人に紐づいた言葉にしてほしいです。

### 会社の前提（確定済み・変更不可）

- 社名：SIDRA STUDIO（シドラ・スタジオ）／ゲームの企画・開発
- 社名の由来：ローマ神話の海の女神サラキア。ラテン語の sāl（塩）に由来する。
  荒れた海ではなく「穏やかで、陽の光にきらめく広い海」を司る女神。
  海の大神ネプトゥヌスの妃で、半人半魚の海神トリトンの母。
  神の求婚から逃げたサラキアを、1頭のイルカが説得して連れ戻した。
  感謝した神はそのイルカを天に上げ、いるか座（デルフィヌス）にした。
  太陽系外縁天体「120347 サラキア」にも名を残している。
- ロゴ：文字主体のワードマーク。「I」の上に金色の一番星、下に波のアンダーライン。
- カラー：深い海 #0B3B57／海 #1C7FA0／陽に輝く海 #35B0C9／陽光の金 #F0C86A／波の泡 #EAF6FA
- 現在のタグライン：「はじめて海を見た日の気持ちを、まだ知らない物語に。」
- サイトで使っている軸：海がくれる三つの感情
  ①息をのむ美しさ（＝ロゴの波）→ ②その先へのわくわく（＝イルカ）→ ③あとに残る余韻（＝いるか座）
  出会った瞬間・遊んでいる最中・遊び終えたあと、という体験の時間軸に対応させている。
- 状況：第一作を制作中。タイトル・プラットフォーム・時期はすべて未発表。

### 制約（必ず守ってください）

1. 運営人数や体制に触れない。「ひとり」「少人数」「小さなスタジオ」などは使わない。
   規模を売りにも言い訳にもしたくないため。
2. 業界の定型句を避ける。禁止：革新、ソリューション、感動を届ける、笑顔にする、
   世界一、No.1、挑戦し続ける、価値創造、ワクワクをお届け。
3. 抽象語だけで終わらせない。情景か、具体的な判断の形で書く。
4. バリューは標語ではなく「迷ったときに何を基準に決めるか」という判断基準の形で書く。
5. 日本語。一文は短く。飾りすぎない。

### 出力フォーマット（この見出しのまま返してください）

#### 1. 私の人物像
- 判断のクセ：
- 大事にしていること：
- 苦手・避けたいこと：
- そう考えた根拠になる、実際のやり取りやエピソード（3つまで）：

#### 2. パーパス（なぜこの会社があるのか）
- 案A：（30字以内）
- 案B：（30字以内）
- 案C：（30字以内）
- 各案について、その言葉にした理由を1〜2文ずつ
- 推す案とその理由

#### 3. ビジョン（10年後の状態）
- 案A：（40字以内）
- 案B：（40字以内）
- 案C：（40字以内）
- ※「業界No.1」のような抽象語ではなく、10年後に言われたい言葉の形で
- 推す案とその理由

#### 4. バリュー（判断基準・3項目）
1. 見出し（10字前後） — 説明（40字前後）
2. 見出し — 説明
3. 見出し — 説明
- 各項目について、私の実際の言動のどこから導いたかを一言ずつ

#### 5. 届ける相手（一人に絞る）
- その人の年齢・生活・抱えていること
- ゲームを起動する時間帯と、そのときの気分
- 遊び終えたあとに書いてほしいレビューを一文で

#### 6. 使ってほしくない言葉
- 私が嫌いそうな、あるいは私らしくない語彙を5つ、理由つきで

#### 7. 確認が必要なこと
- あなたが判断できず、私本人に確認すべき点があれば列挙してください

### 補足

- 各案は互いに似せず、方向性をはっきり変えてください。
- 自信がない箇所は「推測」と明記してください。事実と推測が混ざるのがいちばん困ります。
- 全体を1つのメッセージにまとめて返してください（あとで別のルームにそのまま貼るため）。

## 返ってきたあとの流れ

1. 回答をこちらのルームに貼る
2. パーパス1文・ビジョン1文・バリュー3項目を確定
3. トップページのヒーロー直下と、スタジオについてのページに掲載欄を新設
4. Concept と「作品づくりの姿勢」を、確定したバリューの言葉に差し替え
5. プレビューで確認 → リポジトリに反映
