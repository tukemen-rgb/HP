以下は、私のスタジオ「SIDRA STUDIO」と、運営するサービス「GAMEYARD」の確定事項です。
これを前提に作業してください。ここに書いていないことは決まっていません。

### 会社（SIDRA STUDIO／シドラ・スタジオ）

- 所在地：神奈川県。法人登記は 2026年11月1日予定。**登記前なので「合同会社」「株式会社」は名乗らない**（会社法第7条）
- 事業は3つ
  1. GAMEYARD の運営（クリエイター向けサービス）— 準備中
  2. ゲームの企画・開発（受託・共同開発を含む）— 第一作を制作中。タイトル・プラットフォーム・時期は未発表
  3. アプリケーションの開発
- 社名の由来：いろんなクリエイターがそれぞれ輝ける場所をつくりたい、という考えから。**語源はサイトに書かない**
- ロゴ：文字主体のワードマーク。「I」の上に金色の一番星、下に波のアンダーライン
  - 一番星＝最初に灯った光／星々＝それぞれのクリエイター／アンダーライン＝星々が並ぶ場所（スタジオ）
- カラー：深い夜空 #0B3B57／夜明けの空 #1C7FA0／明けの光 #35B0C9／星の光 #F0C86A／星あかり #EAF6FA

**パーパス**：クリエイターが、より活躍できる環境づくり。
**ビジョン**：つくり手が「ここでなら力を出しきれる」と言う場所になる。外への展開よりも、まずこの一社を育てきる。
**バリュー**（判断基準）：
1. 考えるより、まず動かす — 資料を厚くするより、先に触れるものをつくって確かめる
2. 大きな決断ほど、ゆっくり — 普段は直感で決める。引き返せない決断だけは、順を追う
3. つくる時間を、何より守る — 手を動かす時間を削ってまで、他を優先しない

### サービス（GAMEYARD）

- ゲームを投稿するためのサイトではない。AI とともにつくる時代のクリエイターが、学び、力を借りあい、作品とその歩みを残す場所
- 向き合う相手は他のサービスではなく、つくる人の孤立そのもの
- 投稿無料・掲載料なし・手数料なし・決済なし。収入は法人向けのサイト外請求のみ
- ランキングは置かない（総合・人気・称号）。代わりに「初めて」を祝う（初投稿・初DL・初コメント・初公開）
- Founder 100：最初の100人。募集ではなく、文化をつくる仲間探し。順位ではなく時代を刻む印
  - Founder がすること：自己紹介／夢を書く／制作開始／制作日記／仲間を応援／試作版（MVP）へのフィードバック
  - 用意するもの（予定）：Founder Badge／Founder Discord／Founder 説明会／Founder Wall／Founder 会議
  - キャッチコピー：最初の100人で、この世界の文化を一緒に作りませんか。
- 参加方法・公開時期は未定

**Mission**：創造する人が育ち、その人がまた、次の創造する人を育てる。
**Vision**：100年後にも、作品だけでなく、挑戦や仲間や教え子まで残っている。
**Core Value**：クリエイターとは、自他共楽で。遊ぶ人には、今までにない感動を届ける。
**目指す世界**：感謝が自然と循環する世界。ゲームはその手段。
**育てたいもの**：人／仲間／文化／作品／歴史

理念は2階層で、混ぜない。会社は Purpose / Vision / Values、サービスは Mission / Vision / Core Value。

### 文章の制約（必ず守る）

1. 運営人数や体制に触れない。「ひとり」「一人」「少人数」「小さなスタジオ」は使わない
2. 使わない語：革新、こだわり、ソリューション
3. 設立予定日を書かない。社名の語源を書かない
4. 抽象語だけで終わらせない。情景か、具体的な判断の形で書く
5. 日本語。一文は短く。飾りすぎない
