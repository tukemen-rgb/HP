# 公開前チェックリスト

サイトの中身は完成しています。ここに残っているのは、**人にしかできない手続き**と、
その結果をサイトへ反映する作業です。

自動で判定できる項目は `npm run check` が見ています。手動の項目だけ、ここで管理します。

```bash
npm run check      # 静的チェック（リンク、meta、禁止語、差し替え残り）
npm run visual     # ブラウザでの表示チェック（横スクロール、JSエラー、キーボード操作）
npm run verify     # 上の2つをまとめて実行
npm run shots      # 全ページのスクリーンショットを .preview/ に保存
npm run build:og   # OG画像を再生成
npm run serve      # http://localhost:4173 でローカル確認
```

## 自動チェックが見ている項目

`npm run check`

- 内部リンクと参照ファイルの存在
- HTML タグの開閉
- `title` / `meta description` / `viewport` / `lang` の有無
- `canonical` / `og:title` / `og:image` の有無
- `img` の `alt`
- `h1` の個数
- 仮ドメイン・仮メールアドレス・未記入欄の残り
- 使わないと決めた語（革新／こだわり／運営人数に触れる表現／旧ブランド語）
- `sitemap.xml` と実ページの対応
- OG画像が元データより古くなっていないか
- ページ内アンカー（`about.html#gameyard` など）の参照先が実在するか
- JSON-LD が壊れていないか、パンくずのあるページに BreadcrumbList があるか
- 英語だけの表示要素に `lang="en"` があるか
- `site.webmanifest` の icons の実在・start_url・theme_color の整合
- フッターの年号が今年か

`npm run validate` … html-validate（HTML の構造・属性）
`npm run lint:css` … stylelint（無効な値・重複セレクタ・非推奨プロパティ）

`npm run visual`

- JavaScript のエラー
- 横スクロールの発生（320 / 768 / 1440px）
- キーボードによるモバイルメニューの開閉と、開いた状態でフォーカスが背後へ抜けないか
- 極端に小さい文字
- 文字と背景のコントラスト比（WCAG AA）
- JavaScript を切った状態で本文が見えるか
- 印刷したときに本文が出るか、濃い背景が残っていないか
- 外部の応答が遅いときに本文の描画が待たされないか
