# SALACIA STUDIO — ブランドヒアリングシート

パーパス／ビジョン／バリューを決め、そのままサイトの文章に反映するための質問集です。

- 全 33 問。うち ★ の 6 問だけでも、原案は組み立てられます。
- 所要時間の目安：★のみ 30分／全問 90分。
- きれいにまとめようとせず、話し言葉のまま、具体的な固有名詞と実際の出来事で書いてください。整えるのはこちらでやります。
- 答えられない・決まっていない項目は「未定」と書いてください。空欄のままでも進められます。

回答をいただいたあとの流れ：

1. パーパス1文・ビジョン1文・バリュー3〜5項目を、それぞれ3案ずつ提示します
2. 選んでいただいた案をもとに、各ページの文章へ反映します
3. 変更内容はプレビューで確認できるようにします
