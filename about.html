Aboutスタジオについて

Message

つくる人が、
力を出しきれる場所を。

ゲームの出来は、つくる人がどれだけ力を出しきれたかに左右されます。 手を動かせる時間がどれだけ確保できるか、判断がどれだけ速く通るか、 迷ったときに立ち返れる基準があるか。作品の差は、たいていそこで生まれます。

SIDRA STUDIO は、その環境をつくることを目的に置いたスタジオです。 ひとつの大きな光ではなく、いくつもの光が並んでいる状態。 関わる人がそれぞれの明るさで輝ける場所であることを、まず目指します。

目指しているのは、つくり手が「ここでなら力を出しきれる」と言う場所です。 外に広げることよりも、まずこの一社を育てきることを選びます。

SIDRA STUDIO 代表

Values

迷ったときに、何で決めるか。

  • 考えるより、まず動かす資料を厚くするより、先に触れるものをつくって確かめる。
  • 大きな決断ほど、ゆっくり普段は直感で決める。引き返せない決断だけは、順を追う。
  • つくる時間を、何より守る手を動かす時間を削ってまで、他を優先しない。
The Name

それぞれが、
自分の光で輝ける場所に。

SIDRA という名前は、いろんなクリエイターがそれぞれ輝ける場所をつくりたい、 という考えからつけました。

ひとつの光ではなく

強い光がひとつあれば、周りの光は見えなくなります。 そうではなく、いくつもの光が同じ空に並んでいる状態を目指しています。 誰かの明るさが、隣の光を消してしまわないこと。

まだ、ひとつめ

ロゴの「I」の上にある金色の点は、最初に灯った星です。 これから増えていく光の、ひとつめという意味を持たせています。

  • 一番星（金の点）最初に灯った光。これから増えていく星の、ひとつめ。
  • 星々それぞれのクリエイター。同じ空に、別々の明るさで並ぶ。
  • アンダーライン星々が並ぶ場所。スタジオそのものを表す線。

ゲーム以外のアプリケーションの企画・開発。つくる人の手が止まらない道具をつくることも、同じ目的の内側にあります。

GAMEYARD

つくることが、
孤独な作業でなくなるように。

GAMEYARD は、ゲームを投稿するためのサイトではありません。

  • 学ぶAI とともにつくるための知識と手順を、持ち寄って共有する。
  • 力を借りる自分だけでは越えられない場面で、助けを求められる。
  • 残す作品と、そこに至るまでの歩みを、記録として残していく。

向き合っている相手

  • 他のサービスではない比べる相手は、投稿先でも配信先でもない。
  • 孤立そのものつくる人が誰にも頼れないまま抱え込んでしまう状況を、なくしたい。

目指す世界

  • 感謝が循環する教わった人がいつか教える側になり、助けられた人が次に助ける側にまわる。
  • ゲームは手段つくることそのものではなく、その先の関係を目的に置く。

育てたいもの

  • 人つくる技術と、つくり続ける力。
  • 仲間自分だけでは越えられない場面を、一緒に越える相手。
  • 文化初めての投稿も、初めての感想も、当たり前に祝われる空気。
  • 作品世に出たものと、そこに至るまでの試行のすべて。
  • 歴史誰が誰から学び、誰を育てたのかという記録。
Mission

創造する人が育ち、その人がまた、次の創造する人を育てる。

Vision

100年後にも、作品だけでなく、挑戦や仲間や教え子まで残っている。

Core Value
  • クリエイターとは自他共楽で。関わる人が互いに楽しめる関係を土台に置く。
  • 遊ぶ人には今までにない感動を届ける。
